# Common Mistakes

- Coding Directly on Main
- Creating a Vague Issue
- Only Validating on the Frontend
- Committing Everything Blindly
- Merging Without Testing
- Assuming Deployment Means Success
- Exposing Environment Variables

# Recap

Idea → Code → GitHub → Review → Deployment → Bug fix
